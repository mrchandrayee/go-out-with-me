A playful interactive date proposal featuring an original SVG bunny & bear couple, confetti burst on YES, and a NO button that runs away. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🐰🐻 **Original SVG characters** — white bunny & caramel bear couple
- 🎊 **Confetti explosion** on YES
- 💖 **"Yay! It's a date!"** celebration message
- 🏃 **Runaway NO button** — dodges your cursor
- 🔁 **Replay** — ask again
- 📱 **Responsive** — works on mobile & desktop
